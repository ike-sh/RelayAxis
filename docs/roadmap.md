# 后续工作

下一步优先在独立 Debian 13 测试机完成已有核心实现的系统验收，再扩大增强功能范围。

1. **系统验收**：新装、重复安装、失败升级、真实 systemd 状态与监听健康检查、断电恢复日志、普通卸载和完全清理后的外部服务保护。
2. **真实网络验收**：两台 Ingress、真实 NAT Controller、双物理 IPv4 出口、多个 IPv6 地址、不同 TCP/UDP 应用负载、WG 断线与 SSH 丢失、离线撤销和重连后的完整快照收敛。
3. **生产兼容性验证**：取得官方脚本可核验版本，补充 service/drop-in 的兼容样本，在测试克隆中验证现有日本与香港服务迁移。仍保持外部 PBR / IPv6 / DDNS 的管理边界。
4. **Mimic 增强**：在有独立管理通道的两端测试内核/BTF/DKMS/XDP 兼容性，设计带远端自动回退计时器的双端协调切换；首版只提供真实本端控制和双端核验。
5. **长期运维**：增加备份/应用日志的可配置保留策略、长连接与资源占用压力测试、更多发行版和 CPU 架构的固定依赖校验。

暂不计划防火墙管理、自动内核调优、全局 WG 默认路由、IPv6 落地出口、GOST MTCP 或 PathLock。
