# 后续工作

下一步优先在独立 Debian 13 测试机完成已有核心实现的系统验收，再扩大增强功能范围。

1. **Debian 13 系统验收**：新装、v0.1.0 升级、Netplan plan/apply 的真实 SSH 回滚计时器、整机重启、networkd 包升级/重载、断电恢复日志，以及“普通卸载保留原生片段、完全清理前显式删除片段”流程的实机复核。
2. **真实网络验收**：分别以 9929、CN2、普通 BGP 作为 main 默认路由，覆盖双/三物理 IPv4 出口、动态源地址、两台 Ingress、真实 NAT Controller、多个 IPv6 地址、不同 TCP/UDP 应用负载、WG 断线与 SSH 丢失、离线撤销和重连后的完整快照收敛。
3. **迁移兼容性验证**：在测试克隆中导入多种旧 oneshot ExecStart/ExecStop 与 Realm 反向依赖样本，完成重启前后审计。v0.1.1 只自动迁移具有 RelayAxis 所有权记录的标准旧 unit；其他服务保持只读。
4. **Mimic 增强**：在有独立管理通道的两端测试内核/BTF/DKMS/XDP 兼容性，设计带远端自动回退计时器的双端协调切换；首版只提供真实本端控制和双端核验。
5. **长期运维**：增加备份/应用日志的可配置保留策略、长连接与资源占用压力测试、更多发行版和 CPU 架构的固定依赖校验；为 NetworkManager 等后端实现独立适配器，在实现前继续只读。

暂不计划防火墙管理、自动内核调优、全局 WG 默认路由、IPv6 落地出口、GOST MTCP 或 PathLock。
